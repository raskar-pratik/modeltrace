# ModelTrace — Statistical Methodology (`STATISTICAL_METHOD.md`)

## 1. Overview & Null Hypothesis

ModelTrace tests whether responses from a queried **target endpoint** are statistically exchangeable with responses from a **trusted reference configuration** across a pre-frozen suite of $n$ independent prompts under identical nominal sampling settings.

For each prompt $i \in \{1, \dots, n\}$, ModelTrace collects:
- $m$ independent reference responses $Y^{\text{ref}}_{i,1}, \dots, Y^{\text{ref}}_{i,m}$
- $1$ target response $Y^{\text{tgt}}_i$

A frozen scalar scoring function $S(X_i, Y)$ maps each (prompt, response) pair to a real-valued score:
- $R_{i,j} = S(X_i, Y^{\text{ref}}_{i,j})$ for $j \in \{1, \dots, m\}$
- $T_i = S(X_i, Y^{\text{tgt}}_i)$

**Null Hypothesis ($H_0$):** For each prompt $i$, conditional on the prompt $X_i$, the target score $T_i$ and reference scores $(R_{i,1}, \dots, R_{i,m})$ are exchangeable (specifically, i.i.d. draws from the same prompt-conditional score distribution), and responses across prompts $i = 1, \dots, n$ are mutually independent.

## 2. Pre-Registration, Frozen Snapshots & Disjoint RNG Stream Separation

Before any sample attempt is executed, `create_audit` freezes an immutable manifest (`manifest_json`) containing:
- Full versioned snapshots of the `reference_profile`, `target_profile`, and `scoring_profile` (including `model_identifier`, `base_url`, `checkpoint_path`, `checkpoint_revision`, `tokenizer_path`, `chat_template`, `precision`, `device`, and `api_key_env_var` name—never raw secret values).
- Full prompt snapshots (`selected_prompts_snapshot`), `probe_revision_id`, and `probe_revision_hash` (SHA-256 of canonical prompt JSON).
- `score_mode`: `LOCAL_LOGIT_RANK` or `LENGTH_DISTRIBUTION_ONLY`.
- Sampling settings (`temperature`, `top_p`, `max_output_tokens`) and significance level $\alpha$ (screening default: $\alpha = 0.01$, $n = 20$, $m = 8$, $\text{max\_tokens} \le 128$).
- `master_seed`, from which five independent child RNG streams (`reference_seed`, `target_seed`, `tie_break_seed`, `mc_null_seed`, `bootstrap_seed`) are deterministically spawned via `numpy.random.SeedSequence`.

Subsequent edits to profiles in SQLite never alter a created, running, or resumed audit. Repeated significance peeking or early stopping is prohibited; incomplete audits ($< n$ prompts or $< m$ reference responses for any prompt) cannot produce a valid inferential verdict.

## 3. Primary & Fallback Scoring Functions

### 3.1 Primary Score: Local Teacher-Forcing Log Vocabulary Rank (`LOCAL_LOGIT_RANK`)

When a local Transformers reference checkpoint is configured, each response string $Y$ (whether generated by the reference or the target) undergoes **consistent public-text retokenization**:
1. The formatted chat prompt prefix $X_i$ (rendered using the tokenizer's native `chat_template` or a validated explicit override containing `{prompt}`) is tokenized into $L_{\text{prompt}}$ token IDs, and the response text is tokenized into $L_{\text{resp}}$ token IDs: $t_1, t_2, \dots, t_{L_{\text{resp}}}$.
2. If $Y$ is empty, whitespace-only, or produces zero non-padding response tokens, scoring fails explicitly with `AdapterError(error_code="NO_VALID_RESPONSE_TOKENS")`.
3. The concatenated sequence of length $L_{\text{prompt}} + L_{\text{resp}}$ is passed through the reference causal language model in a single teacher-forcing forward pass (`torch.no_grad()`). If any logit is `NaN` or `Inf`, scoring fails explicitly with `AdapterError(error_code="NON_FINITE_LOGITS")`.
4. **Next-token alignment & prompt/padding exclusion:** For each response token position $k \in \{1, \dots, L_{\text{resp}}\}$ where $t_k \ne \text{pad\_token\_id}$, the logit vector $\ell_k \in \mathbb{R}^{|V|}$ at index $L_{\text{prompt}} + k - 1$ predicts token $t_k$. Prompt tokens (`indices < L_prompt`) and padding tokens are strictly excluded.
5. **1-Based Vocabulary Rank & Mean Log Rank:**
   $$\text{rank}_k = 1 + \sum_{w \in V} \mathbb{I}(\ell_{k,w} > \ell_{k,t_k}), \qquad S_{\text{rank}}(X_i, Y) = \frac{1}{L_{\text{valid}}} \sum_{k} \log(\text{rank}_k)$$

### 3.2 Response-Only Fallback: Frozen Unicode Length (`LENGTH_DISTRIBUTION_ONLY`)

When local reference weights are unavailable, ModelTrace supports an explicitly scoped fallback score $S_{\text{len}}(X_i, Y) = \text{len}(\text{NFC}(Y))$. Every record and report produced under this mode is labeled `LENGTH DISTRIBUTION ONLY` and warns that response-length comparisons cannot verify token-level identity or inherit the sensitivity of `LOCAL_LOGIT_RANK`.

## 4. Finite-Sample Randomized Rank Transformation & Theoretical vs. Empirical Uniformity

Floating-point scores are quantized to a frozen grid of $10^{-9}$ (`round(score, 9)`) before comparison. For prompt $i$ with reference scores $R_{i,1}, \dots, R_{i,m}$ and target score $T_i$:
$$a_i = \sum_{j=1}^m \mathbb{I}(R_{i,j} < T_i), \qquad b_i = \sum_{j=1}^m \mathbb{I}(R_{i,j} = T_i)$$
Using the frozen `tie_break_seed`, draw independent $J_i \sim \text{Uniform}(\{0, 1, \dots, b_i\})$ and $U_i \sim \text{Uniform}[0, 1)$, and compute:
$$z_i = \frac{a_i + J_i + U_i}{m + 1} \in (0, 1)$$

**Mathematical Property vs. Empirical Verification Scope:** Mathematically, under the idealized assumption that $(R_{i,1}, \dots, R_{i,m}, T_i)$ are exchangeable and `(J_i, U_i)` are exact uniform draws, $z_i$ has an exact marginal $\text{Uniform}(0, 1)$ distribution in finite samples regardless of tie multiplicity. However, **empirical software tests (such as a 400-sample Kolmogorov–Smirnov non-rejection $p > 0.05$ or observing $0 / 30$ false alarms in synthetic trials) do NOT prove exact uniformity or guarantee a $\le 1\%$ false-positive rate in finite empirical runs**. They serve only as regression checks against gross implementation bugs.

## 5. Cramér–von Mises Aggregation & Monte Carlo Null Calibration

Given sorted $z_{(1)} \le z_{(2)} \le \dots \le z_{(n)}$, ModelTrace computes the Cramér–von Mises statistic against $\text{Uniform}(0, 1)$:
$$W^2_{\text{obs}} = \frac{1}{12n} + \sum_{k=1}^n \left( z_{(k)} - \frac{2k - 1}{2n} \right)^2$$
Using `mc_null_seed`, $B \ge 9{,}999$ independent i.i.d. $\text{Uniform}(0, 1)$ replicates of size $n$ are drawn to compute the finite-sample Monte Carlo p-value:
$$p = \frac{1 + \sum_{b=1}^B \mathbb{I}(W^2_b \ge W^2_{\text{obs}})}{B + 1}$$

## 6. Binomial Confidence Intervals: Wilson Score vs. Exact Clopper–Pearson

For empirical rejection proportions $\hat{p} = k / N$ across $N$ independent calibration or benchmark trials, ModelTrace computes and reports **two distinct two-sided 95% binomial intervals**:

1. **Two-Sided 95% Wilson Score Interval (`wilson_interval_95`):** Inverts the normal-approximation score test (Wilson, 1927) with $z = \Phi^{-1}(0.975) \approx 1.959964$:
   $$\frac{\hat{p} + \frac{z^2}{2N} \pm z \sqrt{\frac{\hat{p}(1-\hat{p})}{N} + \frac{z^2}{4N^2}}}{1 + \frac{z^2}{N}}$$
   *Example:* For $k = 16, N = 20$ ($\hat{p} = 0.80$), the Wilson 95% lower bound is `0.5839826`. For $k = 0, N = 30$ ($\hat{p} = 0.00$), the Wilson 95% upper bound is `0.113513`.
2. **Exact Two-Sided 95% Clopper–Pearson Interval (`clopper_pearson_interval_95`):** Inverts the exact binomial tail probabilities via Beta quantiles (Clopper & Pearson, 1934):
   $$p_{\text{lower}} = \text{Beta}_{0.025}(k, N - k + 1) \quad (0 \text{ if } k=0), \qquad p_{\text{upper}} = \text{Beta}_{0.975}(k + 1, N - k) \quad (1 \text{ if } k=N)$$
   *Example:* For $k = 16, N = 20$, the exact Clopper–Pearson 95% lower bound is `0.563386`. For $k = 0, N = 30$, the exact Clopper–Pearson 95% upper bound is `0.115703`.

## 7. Strict Calibration Validation & Verdict Decision Rule

When importing or evaluating a calibration artifact (`validate_and_recompute_calibration_alternatives` and `check_calibration_compatibility`), ModelTrace:
1. Validates integer counts $N_{\text{trials}} \ge 1$ and $0 \le k_{\text{rejected}} \le N_{\text{trials}}$, recomputes $\hat{p} = k_{\text{rejected}} / N_{\text{trials}}$, `wilson_lower_95`, and `clopper_pearson_lower_95` from the raw integer counts, and **rejects any artifact whose supplied `empirical_power` or `wilson_lower_95` deviates from the recomputed value by $> 10^{-4}$** (blocking forged bounds such as `n_trials=20, n_rejected=16, empirical_power=0.8, wilson_lower_95=0.99`).
2. Requires exact binding across all configuration dimensions before an audit with $p > \alpha$ can receive `CONSISTENT_WITHIN_TESTED_LIMITS`:
   - Exact match on `score_mode`, `probe_revision_id`, `probe_revision_hash`, `stat_engine_method`, and `stat_engine_version`;
   - **Exact validated budget match** (`n_prompts == cal.n_prompts` and `m_reference == cal.m_reference` — no automatic transfer to higher or lower budgets without validated coverage);
   - Exact match on `alpha`, `temperature`, `top_p`, and `max_output_tokens`;
   - Exact match on `is_demo` provenance and full `reference_identity` (reference and scorer `adapter_type`, `model_identifier`, `base_url`, `checkpoint_path`, `checkpoint_revision`, `tokenizer_path`, `chat_template`, `precision`, and `device`);
   - Recomputed adequacy across every alternative: $N_{\text{trials}} \ge 20$, recomputed $\hat{p} \ge 0.80$, and recomputed two-sided 95% Wilson score lower confidence bound $\ge 0.80$ across every covered alternative (meeting the declared policy using an approximate, nominal 95% Wilson interval for each named alternative; marginal counts like $16/20 = 0.80$ with `wilson_lower_95 = 0.5839826 < 0.80` or $23/25 = 0.92$ with `wilson_lower_95 = 0.750312 < 0.80` are rejected as insufficiently certain, whereas $24/25 = 0.96$ with `wilson_lower_95 = 0.804555 >= 0.80` or $25/25 = 1.00$ with `wilson_lower_95 = 0.866525 >= 0.80` pass).

Wilson intervals have approximate coverage; separate per-alternative bounds do not establish simultaneous 95% coverage across all alternatives. Calibration does not establish power for unnamed or unmeasured alternatives.
